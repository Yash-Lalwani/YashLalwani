# Skill icons

- TypeScript, Node.js, and Scikit-learn: [Devicon](https://github.com/devicons/devicon), MIT license. Downloaded from the corresponding `icons/` directories.
- MCP and LangGraph: [Simple Icons](https://github.com/simple-icons/simple-icons), CC0-1.0. Downloaded from `icons/modelcontextprotocol.svg` and `icons/langgraph.svg`.
- RAG: a custom document-and-retrieval illustration for this portfolio; RAG has no single product logo.

Python, Java, SQL, Docker, PyTorch, and AWS reuse the icons already included in the reference bundle. All newly added SVGs are served locally.
